# Ink Explainer Production Constitution (Permanent Master Standard)

> **OFFICIAL STUDIO PRODUCTION CHARTER**  
> Direct reproduction specifications for matching the exact visual, structural, and acoustic caliber of the **Ink Explainer** YouTube channel.  
> This specification supersedes all prior legacy whiteboard or monochrome rules.

---

## Summary of the 6 Non-Negotiable Laws

| Law | Standard | Rationale / Metric |
| :--- | :--- | :--- |
| **1. Cut Cadence** | **2.0s – 3.0s Max per Slide** | Prevents "boring PowerPoint" feel; creates dynamic illusion of movement. Average cut: 2.1s. |
| **2. Mini-World Assets** | **Locked Asset Kit Before Slides** | Character sheet + 3 environment plates created first to guarantee 100% prompt consistency. |
| **3. Google Flow Prompts**| **Structured 5-Part Anchor Syntax** | Uses `@Character` and `@Environment` reference chips to eliminate image iteration cycles. |
| **4. Visual Style** | **16:9 Cel-Shaded 2D Cartoon** | Clean black ink line art (6px), white circular stickman face, flat vibrant color fills, zero 3D/paper textures. |
| **5. High-CTR Thumbnail** | **3-Element Formula at 168px** | (1) Huge expressive face + (2) One bold prop + (3) 2–3 giant words. Evaluated at mobile feed size. |
| **6. Episode 2 Scope** | **2-Minute High-Density Video** | 120 seconds, ~50 visual cuts, fast monetization trajectory in 3–4 videos. |
