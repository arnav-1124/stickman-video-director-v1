## 🚀 How to Port This Module to Other Projects

This folder (`instructions/veo_mastery_and_consistency_playbook/`) has zero external dependencies. You can simply copy this entire directory into any new repository:
```bash
cp -r instructions/veo_mastery_and_consistency_playbook/ /path/to/new_project/instructions/
```
Then reference it inside your project's `.agents/skills/` or prompt generators!
